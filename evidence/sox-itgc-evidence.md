# SOX ITGC Audit Evidence

## Purpose

This folder contains supporting evidence for the simulated SOX ITGC audit and access review project for CloudNova Financial Systems.

The evidence demonstrates how IT general controls were reviewed, exceptions were identified, and remediation actions were documented.

## Evidence Included

- SOX ITGC control matrix
- User access review
- Privileged access review
- Change management testing
- Audit findings
- Remediation plan

## ITGC Areas Reviewed

- User Provisioning
- User Termination
- Quarterly Access Reviews
- Privileged Access
- Segregation of Duties
- Change Management
- Production Approval
- Backup Operations
- Security Logging
- IT Operations

## Final Assessment

The simulated audit identified High and Medium risk control weaknesses requiring remediation to strengthen SOX ITGC audit readiness.
